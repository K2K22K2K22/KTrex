# Contributing

Thanks for wanting to help.

## Setup

```bash
git clone git@github.com:K2K22K2K22/KTrex.git
cd KTrex
python -m pip install -e .
python -m pytest
```

## Pull requests

- Keep changes small and focused on one thing
- Add or update tests for anything you fix
- Run the test suite before you push
- Match the existing style: type annotations on new public functions, no new dependencies

## Bugs

Open an issue with the bug report template. Include your OS, terminal, Python version, and steps to reproduce.

## Feature ideas

Open an issue with the feature request template first, so the approach can be agreed on before you build it.

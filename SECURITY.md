# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Use the Report a vulnerability button on the Security tab of this repository. That keeps the report private until a fix ships. Please do not open a public issue or discussion for it.

For anything that is not a live vulnerability, such as questions about the safety model, use the Q&A category in the GitHub Discussions.

## Scope

KTrex is a local terminal tool. Reports about filesystem safety (undo, preview, path handling, preset validation) are especially welcome.
